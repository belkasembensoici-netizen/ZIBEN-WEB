# ZIBEN Nova OS

Build an intelligent business platform for merchants,
starting with the Algerian market and designed for global expansion.

## Core Modules
- AI Commerce
- AI Marketing Studio
- Order & Customer Management
- Automation Engine
- Analytics Dashboard

## Architecture
- Frontend: HTML, CSS, JavaScript (initial prototype)
- Backend: Planned
- Database: PostgreSQL (planned)
- Automation: n8n
- AI: Gemini API (initial provider)
